Ролики: 1.mp4 ... 7.mp4 (ровно 7).
Постеры: 1.jpg ... 7.jpg — первый кадр, показывается, пока ролик грузится.
Постеры делаются автоматически:  cd public/videos && sh make-posters.sh  (нужен ffmpeg)

Чтобы ролики грузились быстро, сожми каждый так (убирает звук, 720p, старт без ожидания):
  ffmpeg -i исходник.mp4 -vf scale=-2:720 -an -c:v libx264 -crf 28 -preset slow -movflags +faststart 1.mp4
Цель: 1–3 МБ на ролик. Флаг -movflags +faststart обязателен — без него видео не стартует, пока не скачается целиком.
